# Samples

Sample Menhir projects used to test the editor. A project is a folder with:

- `Assets/` — game assets, each with a sidecar `.meta` file (GUID + import settings)
- `ProjectSettings/` — project-wide settings
- `Cache/` — regenerable data, git-ignored

| Project    | What                                                                   |
|------------|------------------------------------------------------------------------|
| `Sandbox/` | A demo scene and a few placeholder assets; opened by default the first time the editor is run from this repository |
